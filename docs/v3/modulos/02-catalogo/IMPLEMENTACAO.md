# Implementação do Módulo 02 — Catálogo

**Código implementado:** categorias e produtos no Django Admin; catálogo público, pesquisa, filtro, ordenação, paginação, detalhes, anúncios Shopee, validação HTTPS e domínio, redirecionamento, contagem de cliques separada de vendas, estado de anúncio indisponível.

**Rotas:** `/produtos/`, `/produtos/<slug>/`, `/comprar/shopee/<id>/`.

**Testes:** `python manage.py test catalogo` — execução no GitHub Actions pendente de confirmação.

**Pendente de homologação:** responsividade e fidelidade visual em navegador; testes E2E; configuração de produtos reais e links válidos; evitar contabilizar clique como venda. Não existe checkout interno.
